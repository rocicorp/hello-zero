# Hello Zero

React quickstart for [Zero](https://zero.rocicorp.dev/).

## How to Run

First, install dependencies:

```sh
pnpm i
```

Next, run docker:

```sh
pnpm dev:db-up
```

**In a second terminal**, run the zero cache server:

```sh
pnpm dev:zero-cache
```

**In a third terminal**, run the Vite dev server:

```sh
pnpm dev:ui
```
